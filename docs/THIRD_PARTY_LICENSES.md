# Pihak ketiga dan hak cipta

**Tidak satu pun dari source/JAR Kilt, Skarrier Mobs, Cult of Azazel, Cataclysm, GeckoLib, Curios, atau Lionfish API disalin ke ZIP ini.** Hanya string nama mod, metadata format, dan link resmi yang dipakai.

| Project | Pemilik / status lisensi publik | Kebijakan Smooth Bridge |
|---|---|---|
| Kilt | KiltMC, LGPL-2.1-only | Diunduh user secara terpisah; tidak di-fork/dibundel. Jika nanti fork, wajib patuhi notice/source LGPL |
| Skarrier Mobs | Skarrier, All Rights Reserved | Hanya JAR asli user secara lokal; tak boleh redistribusi/port tanpa izin |
| Cult of Azazel | Benj1kus/team, MIT pada listing | Download user sendiri; mod asli tidak termasuk |
| L_Ender's Cataclysm | MCL_Ender, custom/CC BY-NC-ND untuk source, assets reserved | Jangan distribusi modifikasi/port tanpa persetujuan |
| GeckoLib, Curios, Lionfish API | Lisensi masing-masing developer | Download resmi tiap loader/version; tak termasuk paket |

Source Smooth Bridge orisinal sendiri MIT, author **Marj4n**. Lisensi Smooth Bridge tidak menggantikan atau mengubah lisensi upstream.
